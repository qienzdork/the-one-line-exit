# The One-Line Exit

A program that writes one funny one-line resignation letter to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

It writes a single line — a lighthouse keeper resigning because the sea and he
have agreed to see other people — and nothing else.
